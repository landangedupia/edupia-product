\# Edupia Product OS



Product knowledge base and product management workspace for Edupia.



\## Purpose



This repository is the source of truth for product strategy,

discovery, product concepts, requirements, decisions,

experiments, metrics, and product learnings.



\## Repository structure



\- `00\_context/` — Product context and domain knowledge

\- `01\_strategy/` — Product strategy, goals, and roadmap

\- `02\_discovery/` — Research, insights, hypotheses, opportunities

\- `03\_product/` — Product model, taxonomy, concepts, features

\- `04\_delivery/` — Specs, epics, tickets, releases

\- `05\_data/` — Metrics, events, experiments

\- `06\_decisions/` — Product decisions and ADRs

\- `07\_feedback/` — User feedback and learnings

\- `08\_archive/` — Historical and deprecated materials



\## AI agents



This repository is designed to be used with:



\- Claude Code

\- VS Code + Claude Code

\- Google Antigravity



AI instructions are maintained separately from product knowledge.



\## Source of truth



Git is the source of truth for this repository.



Product decisions should be recorded in `06\_decisions/`.



Current product terminology should be maintained in

`03\_product/taxonomy/`.
