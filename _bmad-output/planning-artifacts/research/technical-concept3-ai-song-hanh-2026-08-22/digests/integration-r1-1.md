# Integration & Interoperability (Build vs Buy) — Round 1 Digest

Scope: voice-cloning/custom TTS APIs, real-time conversational LLM APIs, Vietnamese-language TTS state, and voice-cloning legal/consent requirements, for "AI Song Hành" persistent AI-teacher persona.

## Findings

### Voice cloning / custom TTS APIs — pricing & latency

- **ElevenLabs TTS is billed per 1,000 characters: $0.10/1K for the high-quality Multilingual v2/v3 model, $0.05/1K for the faster Flash/Turbo model; Conversational AI (agent speech pipeline) is billed separately at $0.08/min with burst pricing at $0.16/min.** [source: ElevenLabs (official pricing page), accessed 2026-08-22, confidence: high, class: pricing] https://elevenlabs.io/pricing/api — confirmed directly against the primary pricing page (no visible "last updated" date on the page itself, so currency cannot be timestamped beyond today's fetch).
- **ElevenLabs also prices Speech-to-Text at $0.22/hour (Scribe v2) and $0.39/hour (Scribe v2 Realtime), and Voice Changer/Voice Isolator at $0.12/min each.** [source: ElevenLabs pricing aggregator (Puter developer docs) cross-checked against elevenlabs.io/pricing/api, accessed 2026-08-22, confidence: high, class: pricing]
- **ElevenLabs' own production guidance recommends the `eleven_turbo_v2` model with `optimize_streaming_latency: 3` to hit sub-500ms time-to-first-byte for real-time use; official docs steer integrators toward WebSocket streaming for the Conversational AI / Agents Platform rather than plain REST for interactive use cases.** [source: ElevenLabs official docs (Conversational AI WebSocket docs) + dev.to integration writeup, accessed 2026-08-22, confidence: medium, class: integration pain point] https://elevenlabs.io/docs/conversational-ai/libraries/web-sockets
- **Reported production failure modes for ElevenLabs-based voice agents: TTS latency spikes under peak load, voice-quality degradation across non-English languages, audio-chunk overlap/queuing bugs when WebSocket audio events aren't buffered correctly, and API keys being exposed client-side when teams skip a backend proxy.** [source: dev.to developer integration writeup (callstacktech), accessed 2026-08-22, confidence: low-medium, class: integration pain point] https://dev.to/callstacktech/integrate-elevenlabs-for-natural-voice-ai-in-your-application-a-developers-journey-2l8d — single named-but-informal account, not corroborated by a second independent production post-mortem this round; treat as a lead, not a settled fact.
- **Cartesia's Sonic TTS API claims sub-90ms/sub-100ms time-to-first-byte, streams over REST, SSE, and WebSocket, and its latest model (Sonic-3.6, shipped ~August 2026) leads the Artificial Analysis speech-model leaderboards on both "Provider Voice" and "Controlled Voice" arenas; Sonic-3.6 is beta/API-only while docs still list Sonic 3.5 as the stable default.** [source: Cartesia official product page + MarkTechPost, pub date 2026-08-18, accessed 2026-08-22, confidence: medium, class: performance/landscape] https://www.cartesia.ai/sonic ; https://www.marktechpost.com/2026/08/18/cartesia-ships-sonic-3-6-a-streaming-tts-model-that-now-leads-both-artificial-analysis-speech-arenas/ — latency figure (sub-90ms) is a vendor marketing claim, not independently reproduced; flagged low-confidence on the exact number, medium on directional claim (Cartesia is competitive on latency).
- **PlayHT offers a real-time voice-cloning/TTS API with cross-language voice cloning (preserves speaker voice/accent while dubbing across languages); professional-tier voice cloning quality requires PlayHT's higher "Unlimited" tier or above; API access is gated to the Studio-plan-and-up tier for higher-volume developer workflows.** [source: aggregator roundup (Deepgram "Best TTS APIs 2026", starpop.ai PlayHT voice-cloning guide), accessed 2026-08-22, confidence: low, class: pricing/feature] — this is aggregator-sourced, not confirmed against PlayHT's own pricing page this round; treat pricing figures as unverified and follow up against play.ht/pricing directly.

### Real-time conversational LLM APIs

- **OpenAI's Realtime API (current model family gpt-realtime-2.1 / gpt-realtime-2.1-mini) prices audio input at $100/1M tokens (~$0.06/min) and audio output at $200/1M tokens (~$0.24/min), with cached audio input reduced to $20/1M tokens; typical full-agent runs are reported at $0.06–$0.11/min on the full model and $0.02–$0.05/min on the mini once prompt caching is active.** [source: OpenAI official announcement + forasoft cost breakdown, accessed 2026-08-22, confidence: medium, class: pricing] https://openai.com/index/introducing-the-realtime-api/ ; https://www.forasoft.com/blog/article/openai-realtime-api-pricing — two-source corroboration for the per-minute figures, but the forasoft numbers are a third-party derivation, not lifted verbatim from OpenAI's own pricing page (not independently re-verified against platform.openai.com/pricing this round).
- **OpenAI reports the Realtime API's improved prompt caching cut p95 latency by "at least 25%" across all Realtime voice models as of a July 2026 update, and states end-to-end Realtime latency is approximately 300ms, versus 600–1,100ms for a cascaded STT→LLM→TTS pipeline.** [source: TechTimes, pub date 2026-07-07, accessed 2026-08-22, confidence: medium, class: performance] https://www.techtimes.com/articles/319860/20260707/openai-realtime-api-cuts-voice-agent-latency-25-adds-reasoning-mini-model.htm — this is a vendor-supplied benchmark relayed by a tech-news outlet, not an independent third-party measurement; treat the specific "300ms" and "25% p95 reduction" numbers as vendor-claimed, directionally credible given they update a previously known cascade-latency baseline.
- **A new mini "reasoning" Realtime model (gpt-realtime-2.1-mini) was released alongside the July 2026 update specifically targeting lower-cost, lower-latency voice agents with tool-use/reasoning capability retained.** [source: MarkTechPost, pub date 2026-07-06, accessed 2026-08-22, confidence: medium, class: landscape/ecosystem] https://www.marktechpost.com/2026/07/06/openai-gpt-realtime-2-1-mini-reasoning-realtime-api/

### Vietnamese-language TTS / voice cloning

- **Vietnamese voice cloning is served almost entirely by open-source/self-hosted projects, not by the major commercial voice-cloning vendors (ElevenLabs/Cartesia/PlayHT) with dedicated Vietnamese optimization: named projects include VietVoice-TTS, VieNeu-TTS (instant cloning from 3–5s reference audio, runs offline/on-device), v-tts (zero-shot cloning from 3–10s audio, CPU-only), and VietTTS.** [source: GitHub repos (nguyenvulebinh/VietVoice-TTS, pnnbao97/VieNeu-TTS, tronghieuit/v-tts), accessed 2026-08-22, confidence: medium, class: landscape] https://github.com/nguyenvulebinh/VietVoice-TTS ; https://github.com/pnnbao97/VieNeu-TTS ; https://github.com/tronghieuit/v-tts — these are primary (project README) sources but self-reported by the projects' own authors, not independently benchmarked; no production-scale case study found for any of them.
- **Azure's standard (non-cloned) neural TTS supports Vietnamese via a single prebuilt voice, `vi-VN-HoaiMyNeural`; Vietnamese does NOT appear in Azure's Custom Neural Voice (CNV)-eligible locale list — CNV/custom-voice-cloning capability is documented for languages including en-US, es-ES/MX, de-DE, fr-FR, it-IT, hi-IN, ko-KR, ja-JP, pt-BR, but not vi-VN.** [source: Microsoft Learn, official language-support docs, accessed 2026-08-22, confidence: medium, class: version/compatibility] https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts — read via fetch of the official docs page; the page is large/tabbed and the fetch summary could not produce an exhaustive CNV-eligible locale table, so treat "Vietnamese excluded from CNV" as probable-but-not-fully-confirmed and worth a direct manual check of the CNV-specific doc page in a follow-up round.
- **No evidence found this round that ElevenLabs, Cartesia, or PlayHT publish Vietnamese as a supported instant/professional voice-cloning target language** (Cartesia's Sonic claims "40+ languages and accents" generically but Vietnamese-specific support was not confirmed or denied in retrieved sources). [source: Cartesia product page, accessed 2026-08-22, confidence: low, class: could-not-confirm]

### Legal / rights / consent requirements for voice cloning

- **ElevenLabs requires affirmative consent for both Instant Voice Cloning (a click-through confirmation that the user has the right to clone the voice) and Professional Voice Cloning (an additional verification step before training begins); its Prohibited Use Policy explicitly bans replicating another person's voice without consent or legal right, including for impersonation, fraud, election misuse, or bypassing voice verification.** [source: ElevenLabs official Use Policy + Help Center article, accessed 2026-08-22, confidence: high, class: compliance requirement] https://elevenlabs.io/use-policy ; https://help.elevenlabs.io/hc/en-us/articles/13313778519057-Are-there-any-restrictions-on-what-voices-I-can-upload-for-voice-cloning
- **Under ElevenLabs' commercial terms, only paid-plan users own their generated audio outputs and may use them commercially; free-plan outputs cannot be used commercially and must carry attribution.** [source: terms.law commercial-rights summary, cross-referenced against ElevenLabs terms, accessed 2026-08-22, confidence: medium, class: compliance requirement] https://terms.law/ai-output-rights/elevenlabs/ — third-party legal-summary site, not ElevenLabs' own ToS text; directionally consistent with the Use Policy language found, but the exact commercial-rights clause was not independently re-read from ElevenLabs' raw Terms of Service this round.
- **Vendor-side consent enforcement is largely self-attestation plus traceability, not upfront legal proof-of-rights: ElevenLabs states all generated audio is traceable back to the account that created it (for after-the-fact enforcement/account termination), rather than requiring notarized consent documentation before cloning.** [source: margabagus.com policy summary (secondary), accessed 2026-08-22, confidence: low, class: compliance requirement] — single secondary source, not cross-checked against a second independent account; flagged as a lead for direct primary-source verification against ElevenLabs' current ToS text.

## Leads (for a follow-up round)

1. **Named-voice "AI Song Hành" persona is a real person's voice being cloned for a commercial, continuously-operating product** — the consent/compliance picture found here (self-attestation + traceability, paid-plan-only commercial rights) is thin for a decision this consequential. A follow-up round should pull ElevenLabs' actual current Terms of Service (not summaries) and check whether "Professional Voice Cloning" verification is adequate for a named public figure's voice used at scale, and what indemnification/liability terms apply if consent is later disputed.
2. **Vietnamese CNV/voice-cloning gap is the single most decision-relevant and least-confirmed finding.** None of the three major interactive voice-cloning vendors (ElevenLabs, Cartesia, PlayHT) had confirmed Vietnamese-language cloning support in what was retrieved this round; Azure's CNV locale list appears to exclude vi-VN. This pushes the build-vs-buy calculus toward either (a) English-only AI-teacher voice with Vietnamese handled by open-source/self-hosted models (VietVoice-TTS, VieNeu-TTS, VietTTS — all unverified at production scale), or (b) a hybrid architecture. Needs a dedicated follow-up round specifically querying each vendor's supported-language list pages directly (elevenlabs.io/docs languages, cartesia.ai/docs languages, play.ht supported languages) plus a search for any Vietnamese-market case study using these vendors.
3. **Cartesia Sonic-3.6's leaderboard claim (#1 on Artificial Analysis) is vendor/vendor-adjacent-press sourced only** — worth checking the Artificial Analysis speech-arena leaderboard directly (artificialanalysis.ai) as an independent third party in a follow-up round, since it's the kind of "vendor claims to be best" statement the research brief flags for skepticism.
4. **OpenAI Realtime per-minute cost figures ($0.06–$0.11/min gpt-realtime-2.1, $0.02–$0.05/min mini) were sourced from a third-party derivation (forasoft), not read directly off platform.openai.com/pricing** — a follow-up round should fetch OpenAI's own pricing page directly to confirm these numbers and check for a visible last-updated date.
5. **No production post-mortem or dev-forum "this broke on us in production" thread was found for OpenAI's Realtime API** (only vendor announcements and aggregator cost breakdowns) — worth a dedicated search round (e.g., site:news.ycombinator.com OR site:reddit.com "Realtime API" outage/reliability) given the brief's emphasis on real integration pain over marketing pages.
6. **PlayHT pricing/feature claims here are aggregator-sourced only** — not verified against play.ht's own pricing page. Low confidence; re-verify directly if PlayHT stays a shortlisted vendor.
